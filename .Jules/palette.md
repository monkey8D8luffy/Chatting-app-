## 2024-05-18 - Software Keyboard Blocking Critical UI Actions in Jetpack Compose
**Learning:** In screens where text input triggers a direct navigation or connectivity action (like entering a 6-character connect code in NexusScreen), relying solely on a separate "Connect" button results in a disjointed UX, especially on smaller devices where the software keyboard covers the button. Users expect the keyboard's "Go"/"Done" button to execute the action.
**Action:** Always pair `KeyboardOptions(imeAction = ImeAction.Go/Done)` with `KeyboardActions(onGo/onDone = { ... })` for input fields that represent a terminal action in a flow. Critically, use `LocalSoftwareKeyboardController.current?.hide()` within the action block to ensure the keyboard is dismissed cleanly upon submission, revealing any subsequent UI changes or loading states.
