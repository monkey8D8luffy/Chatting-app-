## 2024-05-18 - Improved Keyboard UX on Android Compose
**Learning:** In Jetpack Compose, explicitly configuring soft keyboard IME actions (`ImeAction.Go` or `ImeAction.Done`) combined with manual `KeyboardActions` mapping is crucial for seamless form submission. Often, users tap the "enter/go" key on their soft keyboards, and without explicit handling, this event doesn't trigger the associated UI action, leaving users confused. Furthermore, explicitly hiding the keyboard using `LocalSoftwareKeyboardController.current?.hide()` upon successful submission provides definitive feedback that the action was received and clears the screen estate.
**Action:** Always map primary actions to the soft keyboard's action button for text inputs designed to submit data or move to the next screen, and ensure the keyboard dismisses on successful action.
