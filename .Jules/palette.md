## 2026-06-24 - Explicit Keyboard Dismissal on Action
**Learning:** In Jetpack Compose, relying purely on `KeyboardOptions(imeAction = ...)` to signal intent is not enough. When a text input serves as the primary trigger for a major action (like a search, or a final form submission moving to a new screen), the software keyboard must be explicitly hidden using `LocalSoftwareKeyboardController.current?.hide()` inside the `KeyboardActions` and the submit button's `onClick`. Otherwise, the keyboard can remain visible, breaking the visual transition and causing a jarring UX.
**Action:** Always pair `ImeAction.Done` or `ImeAction.Search` with `KeyboardActions` that map to a shared action function, and explicitly call `keyboardController?.hide()` within that function to ensure a clean UI state change.
